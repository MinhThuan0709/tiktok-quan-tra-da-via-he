# TikTokFactionWar — Art Bible & Project Guide

## Art Bible
- **Style statement**: Flat-shaded neon tactical arena: saturated crimson vs cyan battalions clashing on a dark obsidian grid, where every unit, shield, and nuke glows against the dark court.
- **Palette** (`Assets/Scripts/Palette.cs`): ArenaFloor `#121629` · ArenaGrid `#1E2642` · FactionTopPrimary `#FF3B5C` · FactionTopSecondary `#FF9EAB` · FactionBottomPrimary `#19D3F0` · FactionBottomSecondary `#A8F2FF` · ShadowDark `#090C16` · AccentGold `#F7C844` · NeutralLight `#EEF4FF`.
- **Mood**: Tactical night court illuminated by glowing territory frontlines, base cores, and unit plasma trails; URP Global Volume with Neutral Tonemapping, Bloom, and Vignette.

## Forward Baton
When building gameplay, feel, audio, shell, or live features, load the `craft-game-floors` skill; if it isn't installed, ask the user whether to run `unity skill install <client>` (ask: never run it without a yes).
